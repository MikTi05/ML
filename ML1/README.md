# ML1 - классификация Online Shoppers Intention

## О проекте

В работе исследуется задача бинарной классификации: необходимо предсказать, завершится ли пользовательская сессия покупкой.

Целевая переменная - `Revenue`:

* `Revenue=True` - сессия завершилась покупкой;
* `Revenue=False` - покупка не была совершена.

Основной метрикой выбран F1-score положительного класса `Revenue=True`. Accuracy используется как дополнительная метрика, поскольку в данных присутствует выраженный дисбаланс классов.

## Структура репозитория

* `research.ipynb` - исследование данных, проверка гипотез, предобработка и обучение моделей;
* `online_shoppers_intention.csv` - исходный датасет;
* `README.md` - описание работы и основные результаты.

## Выбранный датасет

Использован датасет **Online Shoppers Purchasing Intention**.

Он был выбран по следующим причинам:

* решается практическая задача бинарной классификации;
* присутствуют числовые и категориальные признаки;
* наблюдается дисбаланс классов;
* данные позволяют сравнить линейную модель, дерево решений и ансамблевую модель;
* можно исследовать влияние масштабирования, глубины дерева и отбора признаков.

После удаления 125 полных дубликатов в датасете осталось 12 205 наблюдений. Пропущенные значения отсутствуют.

Положительный класс `Revenue=True` составляет около 15,6% данных.

## Гипотезы

1. Из-за дисбаланса классов Accuracy будет заметно выше, чем F1-score положительного класса `Revenue=True`.

2. При глубине Decision Tree больше 10 проявится переобучение: Train F1 продолжит расти, а средний F1 на кросс-валидации снизится.

3. Признак `PageValues` окажется самым важным признаком для предсказания `Revenue`.

4. Decision Tree покажет более высокий F1 положительного класса, чем Logistic Regression, поскольку в данных могут присутствовать нелинейные зависимости и взаимодействия признаков.

5. Масштабирование числовых признаков через StandardScaler улучшит F1 Logistic Regression по сравнению с моделью без масштабирования.

## Предобработка данных

Предобработка реализована через `Pipeline` и `ColumnTransformer`.

Для числовых признаков используются:

* заполнение возможных пропусков медианой;
* StandardScaler для Logistic Regression.

Для категориальных признаков используются:

* заполнение возможных пропусков наиболее частым значением;
* OneHotEncoder с `handle_unknown='ignore'`.

Данные сначала разделяются на обучающую и тестовую выборки. Все преобразования обучаются только на тренировочных данных, что предотвращает утечку информации из test.

## Модели

В работе сравнивались:

* Logistic Regression с масштабированием;
* Logistic Regression без масштабирования;
* Decision Tree с глубиной 5;
* Decision Tree с подбором гиперпараметров;
* Random Forest.

Для оценки использовались:

* Accuracy;
* Precision;
* Recall;
* F1-score положительного класса;
* macro F1;
* ROC-AUC;
* Log-Loss.

Кросс-валидация выполнялась с помощью `StratifiedKFold` на пяти фолдах.

## Результаты проверки гипотез

### Гипотеза 1 - подтвердилась

Accuracy моделей находится в диапазоне примерно от 0,87 до 0,90, тогда как F1 положительного класса - от 0,51 до 0,66.

Из-за преобладания отрицательного класса Accuracy действительно создаёт более оптимистичное представление о качестве моделей.

### Гипотеза 2 - частично подтвердилась

При увеличении глубины Train F1 продолжает расти, а CV F1 начинает снижаться. После глубины 10 разрыв становится особенно выраженным.

При этом снижение качества на кросс-валидации начинается раньше предполагаемого порога.

### Гипотеза 3 - подтвердилась

`PageValues` оказался самым важным признаком по встроенной feature importance настроенного дерева и по permutation importance.

Перемешивание `PageValues` привело к наибольшему снижению F1.

### Гипотеза 4 - подтвердилась

Настроенное Decision Tree получило F1 0,6583, а Logistic Regression с масштабированием - 0,5184.

Результат согласуется с предположением о наличии нелинейных зависимостей или взаимодействий признаков.

### Гипотеза 5 - частично подтвердилась

Logistic Regression с масштабированием показала более высокий средний CV F1:

* с масштабированием - 0,5009;
* без масштабирования - 0,4902.

На тестовой выборке результат также оказался немного выше: 0,5184 против 0,5121.

Улучшение наблюдается в обоих случаях, но оно невелико относительно разброса между фолдами.

## Отбор признаков

Для отбора признаков использован `SelectKBest` с `k=10`.

Результаты Logistic Regression:

* все признаки: средний CV F1 = 0,5009;
* 10 выбранных признаков: средний CV F1 = 0,5032.

Отбор признаков не ухудшил качество и позволил сократить размерность данных.

## Итог

По основной метрике F1 положительного класса лучший результат показало настроенное Decision Tree:

* F1 = 0,6583;
* Recall = 0,7815.

Эта модель обнаруживает наибольшую долю сессий, завершающихся покупкой, но допускает больше ложноположительных предсказаний.

Random Forest показал максимальные Accuracy и ROC-AUC, но более низкий Recall положительного класса.

Итоговый выбор модели зависит от прикладной цели:

* для обнаружения максимального числа потенциальных покупателей предпочтительно настроенное Decision Tree;
* для ранжирования сессий по вероятности покупки можно рассматривать Random Forest или Decision Tree с глубиной 5;
* Accuracy нельзя использовать как единственную метрику из-за дисбаланса классов.
