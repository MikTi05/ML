# Online Shoppers Purchasing Intention

## Датасет

Выбран датасет **Online Shoppers Purchasing Intention** для задачи бинарной классификации целевой переменной `Revenue`.

Датасет выбран потому, что содержит числовые и категориальные признаки, имеет дисбаланс классов и позволяет сравнить несколько моделей и способы предобработки данных.

## Гипотезы

1. Из-за дисбаланса классов Accuracy будет заметно выше, чем F1-score положительного класса `Revenue=True`.

2. При глубине Decision Tree больше 10 проявится переобучение: Train F1 продолжит расти, а средний F1 на кросс-валидации снизится.

3. Признак `PageValues` окажется самым важным для предсказания `Revenue`.

4. Decision Tree покажет более высокий F1, чем Logistic Regression, поскольку в данных могут присутствовать нелинейные зависимости и взаимодействия признаков.

5. Масштабирование числовых признаков через StandardScaler улучшит F1 Logistic Regression по сравнению с моделью без масштабирования.

## Краткие результаты

1. **Гипотеза 1 подтвердилась.** Accuracy моделей составила примерно 0,87-0,90, тогда как F1 положительного класса — примерно 0,51-0,66. Из-за дисбаланса Accuracy действительно выглядит более высокой.

2. **Гипотеза 2 частично подтвердилась.** При увеличении глубины Train F1 растёт, а CV F1 снижается. Переобучение становится особенно заметным после глубины 10, но начинается раньше предполагаемого порога.

3. **Гипотеза 3 подтвердилась.** `PageValues` оказался самым важным признаком по feature importance и permutation importance.

4. **Гипотеза 4 подтвердилась.** Настроенное Decision Tree получило F1 = 0,6583, а Logistic Regression с масштабированием - F1 = 0,5184.

5. **Гипотеза 5 частично подтвердилась.** Масштабирование повысило средний CV F1 Logistic Regression с 0,4902 до 0,5009, но разница оказалась небольшой.

Лучшей моделью по основной метрике стало настроенное Decision Tree:

* F1 = 0,6583;
* Recall = 0,7815.

Отбор 10 признаков через SelectKBest не ухудшил качество Logistic Regression.
