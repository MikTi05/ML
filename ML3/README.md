# Диагностика ИБС по медицинским показателям

ML-проект: сравнение классических алгоритмов и нейронной сети MLP
на датасете UCI Heart Disease (Cleveland).
Домашнее задание #3, курс ML Start 2026.

## Задача

Бинарная классификация наличия ишемической болезни сердца по 13 неинвазивным
и малоинвазивным показателям (303 пациента). Практический смысл — приоритизация
пациентов для направления на ангиографию.

## Данные

UCI ML Repository, processed.cleveland.data: 303 объекта, 13 признаков,
целевая переменная бинаризована (0 = здоров, 1–4 → 1 = ИБС).
